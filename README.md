<h1>Xkeen-Service</h1>

<p>
  Простой скрипт для автоматизации бекап и обновления конфигураций <b>XKeen</b> и <b>Mihomo</b> на роутерах Keenetic / Netcraze
</p>

## ✨ Особенности

- Установка одной командой
- Низкое потребление ресурсов — чистый shell (ash), без внешних зависимостей
- Автопереустановка при повторной установке


## ⚙️ Функционал

- Скрипт создаёт бэкапы (XKeen, Mihomo, Keenetic)
- Обновляет актуальные конфиги из [**моего репозитория**](https://github.com/ChapaGG/Mihomo)
- Работает с планировщиком заданий
